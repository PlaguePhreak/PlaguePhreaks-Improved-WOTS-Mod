Aaron: how to push an update to players (no coding needed)
===========================================================
Players' installers look at your GitHub Releases page and download the newest release.

A. MAKE THE FILES (one click)
1. Put the new Assembly-CSharp.dll in "Mod Files" next to the installer (it's 0.32.19 now).
2. Open "WOTS Mod Installer.exe" from this folder (your copy has an extra button).
3. Click "Make GitHub upload zips" (top right) and say Yes.
   It looks at your game's StreamingAssets\override folder, leaves out every file that is
   the same as the base game's own file, and puts the rest in the folder
   "Release upload" next to the installer:
   - override (mod files only)\   = just our files, so you can look at them
   - override_01.zip, override_02.zip, ...   = the same files, each zip under 2 GB
   - Assembly-CSharp.dll and WOTS Mod Installer.exe
   A window opens on that folder when it's done.

B. PUBLISH ON GITHUB
1. Go to https://github.com/PlaguePhreak/PlaguePhreaks-Improved-WOTS-Mod/releases
   and click "Draft a new release".
2. "Choose a tag": type the version with a v in front, e.g.  v0.32.19  > "Create new tag".
3. Release title: the version players see, e.g.  0.32.19
4. Description: paste the change log.
5. Drag in from "Release upload": Assembly-CSharp.dll, every override_XX.zip, and
   WOTS Mod Installer.exe. Wait until every file shows as uploaded.
6. Click "Publish release". Every player's installer now offers this version.

SMALL UPDATES (DLL only, or a few changed files)
Make a new release (new tag, e.g. v0.32.20) and attach only:
   - Assembly-CSharp.dll
   - override_update.zip (optional) = a zip of ONLY the override files that changed,
     in their folders (e.g. campaign\wawallies\score.txt)
Players keep the big zips they already downloaded and get the update on top.
When a lot of art changes, run step A again and upload all the override_XX.zip files.

RULES
- Names must stay: Assembly-CSharp.dll, override_XX.zip, override_update.zip.
- A release without Assembly-CSharp.dll is ignored by the installer.
- Don't delete the old release that holds the last full set of override_XX.zip files.
- "Set as a pre-release" is fine for tester builds; players still get it.
